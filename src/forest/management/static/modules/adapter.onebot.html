添加 OneBot 账号

登记后配置连接，再启用接收消息。

HTTP POST 模式需在 OneBot 实现中设置此上报地址、相同签名密钥及 API 令牌。正向 WebSocket 模式由 Forest 主动连接 Universal 根端点，不使用上报地址或签名密钥。容器内的 127.0.0.1 指向 Forest 容器；Docker Desktop 连接宿主机可使用 host.docker.internal。

可用变量：{sender}、{text}、{group}。模板回复不调用语言模型。
