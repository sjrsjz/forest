图文记忆

各群保留独立来源与时间主干，共享当前 Bot 的记忆。文本与图片片段分别嵌入；文本模型也能使用图片召回的来源信息。裁剪不调用摘要模型。模型版本由管理员声明，保存配置不代表已验证远端语义质量。
