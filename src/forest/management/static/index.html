        Agent 与模型
        
          
        先配置模型，再将账号的回复模式设为 Agent。所有群消息都进入短期上下文；同群串行、跨群并行，裁剪不调用摘要模型。

        子分析与单次运行预算
        子分析只读取父运行已选定的上下文，不调用工具，也不能直接群发。结果由父 Agent 接收后决定是否采用；父子请求共用本次运行和每日 Bot 预算。
        
            
            
        
            
        实际超时与输出还受父运行剩余时间、模型输出上限约束。启用子分析需要开启模型工具调用。
        
          
        
          
        工具授权
        最多 16 项；开启子分析时最多 15 项，预留一个内置分析工具名额。每项填写 name、component_id、service、contract_major、description、authority（trigger / binding_admin）、approval（always / never）和 effect（read / idempotent / non_idempotent）。工具依据具体触发消息的作者授权。
