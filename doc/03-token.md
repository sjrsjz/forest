# 来源令牌与路径匹配

本文先确定令牌数据结构与匹配语义，再由 `forest-util::token` 实现。该模块只提供值类型与纯操作；调度器绑定可信来源、身份认证、ACL 存储与授权检查仍未实现。

## 1. 身份与权限边界

令牌是一个来源路径，不是可出示后取得权限的密码或凭证。权限由 ACL 表达，不能从路径的父子关系推导。根路径 `/` 也不天然具有管理员权限。

宿主根据已认证入口和实际模块实例建立来源，不信任请求参数中的身份。Wasm 可以构造、传递甚至序列化同样的路径数据，但这些值不能替代宿主维护的真实来源。通用工具库不承担执行隔离，也不通过隐藏 Rust 构造函数假装保证来源可信。

来源主体的框架约定为模块实例、外部用户与宿主内部组件。示意路径如下，具体身份类型尚未冻结为 SDK：

| 主体 | 路径示意 | 约束 |
|---|---|---|
| 模块实例 | `/module/{instance}` | 稳定实例身份，不是包名、线程或某次 Wasm 执行身份 |
| 外部用户 | `/user/{identity-space}/{user}` | 平台与 WebUI 身份空间分开，同一平台用户不按群重复创建 |
| 宿主组件 | `/system/{component}` | 只有真正由宿主发起的操作使用；代模块调用不提升为宿主来源 |

Bot 和群聊主要是目标资源与作用域。ACL 应能表达某用户只管理指定 Bot 或指定群；群管理员不自动成为框架管理员。Bot 的稳定内部身份与平台登录账号分开。

## 2. 调用中的来源

发起者、执行模块和目标作用域分别记录，不能挤进一个不断增长的调用链路径。执行模块由宿主已有的实例信息确定，不需要新增可转交的令牌。

- `A → B` 后保留原始发起者，当前执行模块变为 B。普通 `send`、`call`、排队与异步续执行不清除来源。
- B 读取自己的内部配置，按 B 的表访问权限处理；代用户修改其他配置，按发起用户对目标资源的授权处理。
- 接口调用权与接口执行的用户管理操作是不同授权对象，不能用“能调用管理服务”替代“能修改任意配置”。具体调用上下文及 ACL 接口另行设计。
- 模块自主工作使用模块来源；不能把用户请求重新包装为后台任务以洗掉来源。
- Agent 默认使用自身模块权限。群聊历史、引用、召回内容和模型参数均不能授予权限，也不合并多个参与者的权限。代表用户执行的管理操作必须由明确入口保留该用户来源；自主群管理则须另行明确授予模块权限。
- 平台身份解析属于适配模块；只有宿主认可的认证或事件入口可以建立外部用户来源，普通模块消息正文不具备这一能力。

## 3. 类型与纯操作

`Token<K>` 保存具体路径段，`TokenPattern<K>` 保存匹配模式；`K` 可为上层定义的枚举或 ID 类型。核心匹配只要求相等比较，不解析字符串或动态字典。

`PatternSegment<K>` 只有三种情况：`Literal(K)`、`Any`、`AnyDepth`。具体路径没有“通配符段”这一变体。

库提供根路径、从段构造、只读查看、取得父路径、构造子路径、按段判断前缀和严格祖先，以及精确模式和子树模式。所有操作无 I/O、无隐式授权、不修改原路径。

默认路径段类型 `Segment` 用于配置文本。内部值私有，构造时验证；任意自定义 `K` 的表示规则由其自身类型负责。文本只是路径的输入输出格式，不是运行时接口路由协议。

## 4. 文本格式与通配符

文本路径必须以 `/` 开始，根路径为 `/`。非根路径由非空段组成，不接受连续 `/`、尾部 `/`、`.`、`..`、反斜线、空白或控制字符。普通段保留 Unicode 原值，不做大小写折叠、URL 解码、修剪或 Unicode 归一化。`%2F` 是字面文本，不是分隔符。

`*` 为保留字符，只允许在模式中作为完整的 `*` 或 `**` 段出现。不支持段内通配符、正则表达式或转义语法；`?` 是普通字符。

| 模式 | 含义 |
|---|---|
| `/module/a` | 只匹配该路径，不匹配 `/module/ab` 或 `/module/a/x` |
| `/module/*` | 恰好匹配 module 下的一段，不匹配 `/module` 或更多层 |
| `/module/**` | 匹配 `/module` 本身及其全部后代 |
| `/**` | 匹配所有路径，包括根路径 |
| `/bot/*/module/**` | 匹配各 Bot 下 module 节点本身及其后代 |
| `/a/**/b` | 匹配 `/a/b`、`/a/x/b` 等，仍须匹配完整路径 |
| `/` | 只匹配根路径 |

`**` 可以出现在任意段位置，可以重复。匹配整个具体路径，区分大小写。实际来源不能从带 `*` 的文本解析得到。

匹配采用迭代算法，记录最近的 `**` 及其尝试位置，不递归展开所有组合。辅助空间为 O(1)，最坏比较次数为 O((模式段数 + 1) × (路径段数 + 1))；不宣称任意模式均为线性时间。

## 5. 本次实现范围

实现路径、模式、文本格式化/解析和结构化解析错误，不附带 ACL 引擎、授权继承、身份会话、签名、过期或委派机制。来源与目标可以复用路径匹配算法，但应在上层用不同资源类型区分，避免把来源路径误当成目标对象。

热重载保留稳定模块身份，不通过包名、构建版本或 Wasm 地址重建权限。宿主停止接收已退出执行实例的请求；令牌工具库不管理实例生命周期。
