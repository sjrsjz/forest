# Forest 设计文档

本目录记录 Rust 新主线的设计与实现边界。当前已实现序列化库、令牌路径工具和独立 OneBot API 库；运行时文档记录讨论所得的设计方向，不代表相关功能已经存在。

| 文档 | 内容 | 状态 |
|---|---|---|
| [序列化说明](serialization.md) | Forest 序列化移植、转换语义与限制 | 已实现 |
| [模块运行时架构](01-module-runtime.md) | 微内核职责、插件包、实例、接口与通信 | 设计记录 |
| [状态与访问详细设计](02-state-access-and-reload.md) | 宿主状态表、来源路径、ACL、UI 与热重载交接 | 设计记录 |
| [来源令牌与路径匹配](03-token.md) | 来源与 Bot 作用域、泛型路径、通配符、文本格式 | 路径与匹配已实现，宿主绑定及授权待实现 |
| [OneBot v11 API 库](04-onebot-v11.md) | 现有库评估、38 个公开 API、异步传输与错误语义 | 类型及原生 HTTP 已实现，Wasm 插件与事件传输未实现 |

文档中的“待定”表示尚未形成决定。编写对应实现前应继续讨论，不能把示例名称或先前提案直接固定为接口。

当前采用宿主托管状态表与“调度器生成来源路径＋ACL”的方向。此前讨论的强制 `snapshot` 交接、完整委派令牌树及自动重载超时均未采用。

旧 Python 实现及其设计文档保存在 `archive/python-2026-10-19` 等归档分支中，不作为新主线的设计依据。
