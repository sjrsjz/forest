# 删除上下文估算硬阻断

Agent 5.7.0、Conversation 5.3.0 移除了按本地上下文估算量终结 Run 的路径。选择器保留必要触发、已经提交的工具因果组及已冻结历史；即使这些内容超过模型视图选择目标，仍发布计划并调用模型。目标只决定是否继续加入可选历史与召回，既有自动归档和裁剪继续由 Conversation 管理。

删除内容包括选择器的预算异常、Agent 的错误转换和 FAILED 分支，以及对应的 SQL/schema 终态契约。无效来源或成本事实仍按输入契约错误处理，不再冒充预算超限。真正序列化字节上限保持独立，不使用 token 估算判定。

验证结果：56 项模型、计划与选择器检查，2 项包/配置检查均通过；Ruff 通过。隔离 PostgreSQL 的 2 项集成检查通过（181.72 秒）：完整 BotHost 将模型视图目标设为 1024 token，确认发布计划的总估算成本超过目标，仍实际调用 Provider，输出额度保持 16384；Agent 包的真实字节超界事务仍按运行所有权和模型边界结算。删除了只用于证明旧预算失败终态的测试块。

更新使用离线维护事务：比对旧制品基线，只替换 Agent 的一个指定函数，与两份新制品选择原子提交；没有修改表定义、删除业务记录或加入运行时兼容代码。两份原配置的修订及内容摘要保留。

运行实例已恢复 ONLINE，RuntimeGraph 55、25/25 ACTIVE；精确制品身份和两份配置摘要已只读复核，原唯一只读观察器已恢复。没有主动重放已失败 Run 的工具副作用，也没有主动发送真实群消息。
