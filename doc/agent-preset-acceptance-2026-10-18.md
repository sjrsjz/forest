# Bot 提示词编辑验收（2026-10-18）

原界面只提供 Agent 核心协议的只读查看与创建期人格编辑，缺少现有 Bot 的人格设置入口。Agent 5.3.0 的工作区默认打开“Bot 提示词”，另有“执行记录”和“核心协议（只读）”视图。管理员可以读取、编辑、按顺序添加及移除人格段落，经“检查提示词计划”和外层“应用计划”发布配置。

通用管理宿主按准确包清单的 `configuration_documents` 声明处理 JSON 文档，没有 Agent 专用 HTTP 路由或人格存储表。计划在鉴权、幂等和配置修订 CAS 的同一事务中生成模块所有的不可变文档与配置引用；读取只核对并返回文档，不能触发写入。新的配置 Payload 依赖其文档 Payload，应用与换代使用已有协议。Agent 配置 Schema、Run 冻结规则与 SQL 基线不变，发布可保留既有 Bot 和记忆库。

隔离 PostgreSQL 验证通过：无效同级字段导致已物化文档回滚、UTF-8 大小拒绝、同操作并发返回相同计划、旧生效文本保持不变、陈旧配置修订不产生新 Payload、其他模块所有的引用不能冒充本模块预设。正式 BotHost 场景经管理 Contract 生成计划、提交配置并替换运行图，期望/生效文本一致，模型请求只使用新人格，Run 的预设引用与生效配置一致（1 passed in 126.79s）。均使用模拟模型与 OneBot，没有付费模型调用或真实群消息发送。
