# 触发策略控制页与群发现

## 职责与接口

`conversation.trigger-policy` 随包提供管理 UI，编辑该 Bot 的 `allowed_group_ids`、群触发方式和私聊开关。内核只提供已有的 UI 消息通道、查询路由和配置计划/提交能力，不持有 QQ 群目录。勾选只改变草稿，仍须生成并应用配置计划；不直接写数据库。

群成员关系由 `adapter.onebot` 负责发现。管理页通过 trigger-policy 的管理查询，消费 Adapter 的 `adapter.onebot.groups.page/1` 只读服务，不读取 Adapter 配置、凭据或表。该依赖为可选、非启动依赖，避免 Adapter 启动依赖触发分类器时形成环。发现失败不影响分类服务，也不清空白名单。

Adapter 服务先列出当前 Generation 中启用的账号绑定，再按绑定查询群。底层仅开放 `get_group_list`，不开放任意 OneBot action。它复用该 Adapter Generation 已验证账号的 WebSocket；发送驱动仍是连接、凭据和监听任务的唯一所有者。只读驱动视图通过同一工厂中的弱引用绑定查找所有者，不拥有或关闭第二套连接。调用校验 Generation、RuntimeGraph 和绑定身份；热重载后不能访问旧连接。

OneBot 官方 [`get_group_list`](https://github.com/botuniverse/onebot-11/blob/master/api/public.md) 返回完整列表，不提供分页。传输层对完整响应设置独立有界上限，校验群 ID、名称及重复记录；Adapter 对结果按群 ID 排序、按名称/ID 筛选，再输出至多 25 条。分页游标是最后一个群 ID。每页是一次实时读取，不宣称提供跨页事务快照；加入/退出群后刷新即可。UI 不循环自动拉完全部页，不产生群聊消息。

## 管理交互

页面包含账号选择、名称/群号搜索、群列表勾选，以及触发方式和私聊开关。列表使用有界滚动区域，支持下一页。额外显示完整已选集合，允许移除当前页、当前筛选或当前账号中未显示的已有配置，避免翻页丢失选择。所有群名以文本节点渲染。

多个账号属于同一 Bot 时，白名单仍采用既有 Bot 级群 ID 语义；同一群在不同账号下的勾选一致，不新增隐含的账号级策略。账号来源由绑定名和账号 ID 明示。

账号不可用、模块未安装、调用超时或协议错误均在发现区域显示错误；草稿和已有选择继续保留，禁止以空响应代替成功。只有用户显式勾选/移除才修改集合。刷新不会提交配置。群白名单限制的是自动触发 Agent，并不表示禁止接收、归档或召回该群消息。

## 生命周期与边界

群发现无持久化缓存、无后台轮询、无新增数据库表。读取不会修改运行意图、群策略或消息状态。只读视图不拥有任务；驱动停止时由原连接所有者关闭资源。分页响应受 Worker IPC 上限约束，外部完整响应上限单独校验，不借此放宽群消息或普通发送回执的限制。
